# R Programming Practicals

Created by **Shiven Dubey** | TYBSc IT – University of Mumbai

A collection of R programming practicals for learning basic operations, data structures, graphs, diagrams, and regression. The supplied college index is followed, and the original practical documents are kept with their corresponding programs.

## Start here

1. Open [INDEX.md](./INDEX.md) and choose a practical.
2. Open its folder and select a `.R` program.
3. Open the program in RStudio and run it.
4. Practical 6 Ridge Regression uses `glmnet`; install it once with `install.packages("glmnet")` if it is not installed.
